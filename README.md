# ระบบบริหารจัดการระบบบำบัดน้ำเสีย โรงพยาบาล ๕๐ พรรษา มหาวชิราลงกรณ (SPA)
> **Wastewater Treatment Management Platform (Production Ready Single Page Application)**

ระบบเว็บแอปพลิเคชัน Single Page Application (SPA) ระดับมืออาชีพ สำหรับติดตาม ตรวจสอบ และบริหารจัดการระบบบำบัดน้ำเสียทางการแพทย์และสิ่งแวดล้อม โรงพยาบาล ๕๐ พรรษา มหาวชิราลงกรณ ออกแบบตามมาตรฐานกรมควบคุมมลพิษและสาธารณสุข เชื่อมต่อฐานข้อมูล Supabase PostgreSQL (พร้อมโหมดจำลองออฟไลน์ในตัว)

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

1. **แดชบอร์ดภาพรวมอัจฉริยะ (KPI Dashboard)**:
   - กรองข้อมูลตาม **วัน / เดือน / ปี** หรือช่วงเวลาที่กำหนด
   - กราฟ Chart.js ความสูงคงที่ `h-72` พร้อมตั้งค่า `maintainAspectRatio: false` ไม่ยืดย้วย แสดงผลสีสันชัดเจนสวยงาม
   - การติดตามน้ำเสียเข้าสู่ระบบ 80%, การใช้พลังงานไฟฟ้า, ค่าไฟฟ้ารวม, อัตราผ่านมาตรฐาน (%) และสถานะเครื่องจักร
2. **บันทึกปริมาณน้ำเสียเข้าสู่ระบบ (Influent Wastewater)**:
   - ดึงเลขมิเตอร์เริ่มต้นล่าสุดจากฐานข้อมูลให้อัตโนมัติ (หรือเว้นว่างถ้าเป็นครั้งแรก)
   - คำนวณ **ปริมาณน้ำใช้ทั้งหมด** และ **ปริมาณน้ำเสีย 80% (ลบ.ม.)** ให้อัตโนมัติทันทีที่กรอก
   - แนบรูปภาพมิเตอร์น้ำ พร้อมระบบ **Image Fallback Error Handling** (แสดงกล่องข้อความและไอคอนแจ้งเตือนแทนเมื่อโหลดรูปไม่ขึ้น)
3. **บันทึกการใช้พลังงานไฟฟ้า (Electricity Consumption)**:
   - ดึงเลขมิเตอร์เริ่มต้นให้อัตโนมัติ
   - คำนวณ **หน่วยไฟฟ้ารวม (kWh)** และ **คิดเป็นค่าไฟ (บาท)** ตามอัตราค่าไฟฟ้าโรงพยาบาล/รัฐวิสาหกิจ
4. **การตรวจวัดคุณภาพน้ำ (Water Quality Inspection)**:
   - **ตรวจคุณภาพน้ำเบื้องต้น**: ตรวจวัด pH (5.5–9.0), DO (2.0–4.0 mg/L), TDS (&le; 500 mg/L), คลอรีนอิสระ (1.0–2.0 mg/L), ตะกอน VS30 (&le; 300 mL/L) พร้อมระบบแจ้งเตือน **ผ่านเกณฑ์ / เกินเกณฑ์** แบบ Realtime
   - **การตรวจวิเคราะห์ประจำไตรมาส**: รองรับ BOD, COD, SS, TSS, TKN, G/O, Sulfide, TCB, FCB ตามมาตรฐานสากล พร้อมแนบไฟล์ผลแล็บ
5. **ตรวจสอบระบบเครื่องจักรและงานซ่อมบำรุง (Machinery & Maintenance)**:
   - ระบบ **ตะกร้าเลือกอุปกรณ์ (Multi-select Checklist Basket)** ที่ดึงข้อมูลจากตารางอ้างอิงอุปกรณ์
   - ปุ่ม **+ เพิ่มอุปกรณ์ใหม่** ได้ทันทีในหน้าฟอร์ม
   - บันทึกงานบำรุงรักษาเชิงป้องกัน (PM) และงานแก้ไขพร้อมควบคุมงบประมาณ
6. **การบริหารความเสี่ยง & เหตุการณ์ผิดปกติ (Risk & Incidents)**:
   - บันทึกความเสี่ยง, ระดับความรุนแรง, ผลกระทบ, แผนป้องกัน และบันทึกเหตุการณ์ฉุกเฉิน
7. **รายงานและการส่งออกข้อมูล (Export & Reports)**:
   - ส่งออก **Excel (XLSX)** ด้วย SheetJS
   - ส่งออก **PDF** รายงานสรุปทางการพร้อมส่วนลงนาม
   - **Print Preview** จัดรูปแบบสวยงามพอดีหน้ากระดาษ A4
   - **ปุ่มสร้างข้อมูลตัวอย่าง 1 คลิก (Seed Sample Data)** ครอบคลุม 14 ตาราง
8. **ระบบสิทธิ์และการเข้าสู่ระบบ (RBAC & Auth)**:
   - **Super Admin สูงสุด**: Username: `Sangtawan` / Password: `Sangtawan123456789` (จัดการได้ทุกสิทธิ์ ล้างข้อมูลได้)
   - **User / Technician**: สำหรับเจ้าหน้าที่บันทึกข้อมูลประจำวัน

## 🚀 วิธีการติดตั้งและใช้งาน (Installation & Setup Guide)

### ขั้นตอนที่ 1: ติดตั้งฐานข้อมูลบน Supabase
1. เข้าสู่ระบบที่ [https://supabase.com](https://supabase.com) และสร้าง New Project
2. ไปที่เมนู **SQL Editor** ทางแถบซ้าย
3. เปิดไฟล์ `database-schema.sql` ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดไปวางใน SQL Editor แล้วกดปุ่ม **RUN**
4. ตารางทั้งหมด 14 ตาราง พร้อม RLS Policies, Indexes และข้อมูลเริ่มต้นจะถูกสร้างขึ้นทันที

### ขั้นตอนที่ 2: เชื่อมต่อ WebApp เข้ากับ Supabase
1. ไปที่ Supabase Project ของท่าน เลือก **Project Settings** > **API**
2. คัดลอก **Project URL** และ **anon / public Key**
3. เปิดหน้าเว็บแอปพลิเคชัน กดที่ไอคอน **ฐานข้อมูล (Database)** บนแถบ Header ด้านบนขวา
4. นำ URL และ Key มาวางในช่องแล้วกด **บันทึกการตั้งค่า**
5. ระบบจะทำการเชื่อมต่อและซิงค์ข้อมูลกับ Supabase ทันที

*(หมายเหตุ: หากยังไม่ได้เชื่อมต่อ Supabase เว็บจะทำงานในโหมด Offline LocalStore ให้โดยอัตโนมัติ ไม่เกิดข้อผิดพลาด)*

## 🌐 การนำขึ้นใช้งานบน GitHub / Web Hosting

1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นสู่ GitHub Repository:
   ```bash
   git init
   git add .
   git commit -m "feat: ระบบบำบัดน้ำเสีย โรงพยาบาล ๕๐ พรรษา มหาวชิราลงกรณ"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/hospital-wastewater-spa.git
   git push -u origin main
   ```
2. ไปที่ **Settings** ของ Repository บน GitHub > เลือกหัวข้อ **Pages**
3. ในส่วน **Build and deployment** ให้เลือก Source เป็น **Deploy from a branch** (Branch: `main` / `root`)
4. กด **Save** รอประมาณ 1 นาที จะได้ลิงก์ URL พร้อมใช้งานทันที

## 📊 เกณฑ์มาตรฐานคุณภาพน้ำทิ้งโรงพยาบาล

- **ค่า DO (Dissolved Oxygen)**: `2.0 – 4.0 mg/L`
- **ค่า TDS (Total Dissolved Solids)**: `&le; 500 mg/L`
- **ค่าความเป็นกรด-ด่าง (pH)**: `5.5 – 9.0`
- **ค่าตะกอน VS30**: `&le; 300 mL/L`
- **ค่าคลอรีนอิสระตกค้าง (Residual Chlorine)**: `1.0 – 2.0 mg/L`
- **BOD**: `&le; 20 mg/L`
- **COD**: `&le; 120 mg/L`
