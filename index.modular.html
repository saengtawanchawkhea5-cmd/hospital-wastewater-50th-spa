# วันที่เก็บตัวอย่าง จุดเก็บตัวอย่าง BOD / COD / SS TKN / G/O TCB / FCB สถานะมาตรฐาน การดำเนินการ จัดการ

# วัน/เวลา รายการอุปกรณ์ที่ตรวจ สถานะการทำงาน รายการผิดปกติ/สาเหตุ ผู้ตรวจสอบ จัดการ

# วัน/เวลา ประเภทงาน อุปกรณ์ ปัญหา / วิธีแก้ไข ค่าใช้จ่าย ผู้ดำเนินการ จัดการ

# ประจำเดือน น้ำเสียรวม (ลบ.ม.) ไฟฟ้ารวม (kWh) ค่าเฉลี่ยคุณภาพน้ำ อัตราผ่านมาตรฐาน ค่าใช้จ่ายรวม จัดการ
